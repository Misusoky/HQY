# 内容总清单 · 深宫辞

> 用途：UI 精修前的**完整内容蓝图**。设计对象（屏幕/面板）= 你拿进 Kimi Design 的 backlog；
> 玩法功能 = 代码侧任务，不过设计稿。已按批次排好优先级。

## A. 玩法功能（逻辑侧，不占用设计资源）

- 回合状态机：FOCUS_SELECT → NARRATING → EVENT_CHOICE → RESOLVING → TURN_END，事件出现必停等玩家
- API 层：Moonshot 兼容端点（可自定义），JSON 模式，system 提示词拼装（世界书+文风+存档），会话历史近 6 旬摘要压缩，失败重试 1 次
- 结算：statePatch 点号路径合并，属性/才艺 0—100 钳制，关系值不钳制
- 存档：3 手动槽 + 1 自动槽（localStorage），每 5 旬及重大节点自动存档，导出/导入 JSON
- 查询面板：纯本地渲染，不耗回合、不调模型；商城购买进"待生效队列"下轮请求附带
- **NPC 双层档案系统**：真相层驱动言行（只发模型）、视角层渐进解锁（玩家可见，来源可溯）；输出契约加 `dossier` 字段 —— 详见 `FEATURE-NPC档案.md`
- 文本过滤：正文去 emoji / markdown 残留；骨架屏加载；叙事流保留近 20 旬，更早折叠「回顾」
- 深色模式（跟随系统）、新开局按世界书 §14 生成并确认主角档案
- **精力系统（两旬精力版，已实装）**：每月仅上/下旬两旬；每旬 100 精力，行动耗点——才艺25／社交20／宫务20／子女20／休养10／家书10（自定义20）；传膳 5 两回 15；≤20 弹窗劝歇；归零当场昏迷、体质 −5 并强制进入下一旬；一旬内可「再安排一事」连办多事；精力由前端自结不进 statePatch，规则提示词见 ENERGY_MODULE
- **属性合并（已实装）**：心机+野心 → 「忌惮」（宫中众人对主控的忌惮程度，旧档取两值平均）；影响不熟/敌对 NPC 的印象与行为（NPC_MODULE 第 6 条），只随重大事件增减；世界书结算规则同步改为"主控忌惮 vs 对方心机"
