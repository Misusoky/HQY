# 主界面 v2 设计描绘（住处 + 精力制）· 给 Kimi Design 的自然语言稿

> 状态：仅设计 demo，未实装。后端精力逻辑已在 index.html 落地（两旬制、100 精力、行动耗点、传膳、20 弹窗、0 昏迷），本稿描绘主界面改版后的目标形态，供 Kimi Design 出 v2 视觉稿。

## 一、整体概念

打开游戏即「回到主控的住处」。主界面不再是纯文字流，而是一间**古典女子卧房兼小厅的插画场景**（竖屏构图，iPhone 全屏）。玩家在这间屋子里决定这一旬怎么过：点家具是查看与整理，点门是出门，点床是歇下。文字叙事流退居次层——平时折叠在底部，发生剧情时自动滑出。

气质：架空盛唐、宣纸底色、室内昏黄烛光与窗外冷白天光的对比；物件精致但克制，不堆叠。整体延续 v1「深宫辞」的宣纸色、朱砂印章、靛青顶栏三要素。

## 二、画面分区（自上而下）

### 1. 顶栏（保留现有，微调）
- 左：时间印章按钮「元朔四年·腊月下旬」（点开大事记）。
- 中：位份｜银两｜精力数字。
- 右：「传膳」小按钮 + 「积分」按钮（点开商城）。
- 精力数字建议随余量变色：>50 墨黑、21–50 赭黄、≤20 朱砂红。

### 2. 房间插画区（画面主体，约屏高 45–55%）
- 一幅完整的室内场景：前景矮案与坐垫，中景书桌、妆台、琴架、床榻，远处一扇通往廊下的门（半掩，透进天光）。
- **热区可点**（点击后有轻微压暗/描边反馈）：
  - **妆台** → 行囊/妆奁（道具清单）
  - **书桌** → 书信与家族事务
  - **琴架/书架** → 才艺修习入口
  - **床榻** → 休息（同「进入下一旬」，需二次确认）
  - **门** → 出门：展开地图（拜访、闲逛、出行）
- 插画暂无素材：先出**带热区标注的线框色稿**即可，正式插画后补（允许先用低饱和色块+剪影占位）。

### 3. 精力条（房间区下方，常驻）
- 一条横向细进度条，宣纸底、朱砂描边，内填墨色渐变。
- 左端小字「精力」，右端数字「65/100」。
- 填充段随余量变色：充足墨黑 → 过半赭黄 → 将尽朱红。
- 条下方一行小字列出**本旬已办之事**（如「已练《平沙》 · 已拜访韦昭仪」），最多三行，超出折叠。

### 4. 底部主按钮组（四枚大按钮，横排或 2×2）
- **地图**（靛青描边）：展开宫城地图，选去向——各宫拜访、御花园、藏书阁、太医院等；出行耗精力。
- **才艺**（墨黑）：六项才艺现状一览 + 择一修习（耗 25 精力）。
- **宫务**（赭石）：整顿宫人、核查账目、布置眼线等（耗 20 精力）。
- **下一旬**（朱砂实心、最醒目）：结束本旬，休息回满精力。
- 点击任一行动按钮 → 弹出该行动的具体安排浮层（选对象/选项目/填写细节）→ 确认后进入文字叙事（模型生成），完成回到房间。

### 5. 底 tab（保留 v1.1 四个）
状态 / 行囊 / 人物 / 设置。位置不变，视觉上比主按钮组弱一档（小号灰字）。

### 6. 文字叙事流
- 平时收成底部一条「剧情 ▴」小横条；有新叙事时自动上滑展开，读完（或行动结束）后缩回。

## 三、关键交互瞬间

- **传膳**：顶栏点「传膳」→ 小浮层「传膳用毕，精力 +15（现 80）」→ 精力条动画回升。银两不足时浮层提示「银两不足（需 5 两）」。
- **精力 ≤20**：行动结算后弹**居中圆角小卡**（遮罩压暗房间）：标题「精力将尽」，正文一句劝歇的话，两个按钮——「再撑一撑」（关弹窗继续）与「休息，进入下一旬」（主按钮）。
- **精力归零（昏迷）**：不做弹窗，直接在全屏 push 一张「昏迷卡」——画面可轻微压暗再恢复，卡上朱印「昏」，正文一句「眼前一黑……」，体质 −5；随后自动回到房间，精力回满，时间进入下一旬。
- **事件突发**：房间区短暂蒙上一层朱砂描边的提示条（「突发 · 菊宴前有人求见」），点击展开叙事与选项。

## 四、需要 Kimi Design 产出的物料

1. 主界面 v2 全屏稿（住处场景 + 热区标注 + 精力条 + 四主按钮 + 底 tab）。
2. 精力 ≤20 弹窗稿。
3. 昏迷卡稿。
4. 地图展开稿（宫城平面示意，标出可去之处）。
5. 行动浮层通用模板稿（标题 + 选项列表 + 确认按钮）。
6. 设计 token 增量：精力条三色值、弹窗圆角/阴影、主按钮四态（常态/按下/禁用/朱砂主按钮）。

## 五、给 Kimi Design 的一段话提示词（可直接粘贴）

> 为一款古风宫斗文字游戏重设计主界面。竖屏。主界面是主控的古典卧房场景插画（盛唐风、宣纸色调、烛光与天光），画面中有可点击的家具热区：妆台（道具）、书桌（书信）、琴架（才艺）、床榻（休息）、房门（出门/地图）。房间下方是一条常驻精力条（100 满值，墨→赭→朱红三段变色），再下方是四枚主按钮：地图、才艺、宫务、下一旬（朱砂实心最醒目）。底部保留四个弱化的 tab：状态/行囊/人物/设置。顶栏左侧时间印章，右侧传膳与积分。另需三张附属稿：精力将尽的休息建议弹窗、昏迷结算卡、宫城地图展开页。整体气质克制雅致，留白多，呼应「深宫辞」主题。
