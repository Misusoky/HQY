# 红墙引 · 带着系统去宫斗（HTML 版）

在浏览器中运行的宫斗文字游戏。手机/电脑打开 `index.html` 即可游玩，无构建步骤。

## 目录

| 路径 | 用途 |
|---|---|
| `index.html` | 游戏本体：界面、回合状态机、本地存档与模型调用（内联 CSS/JS） |
| `assets/` | 字体、头像、住处与宫城图、PWA 图标 |
| `宫斗模拟器原料/` | 世界书、叙事文风、提示词与存档示例；内联文案的源头 |
| `design/` | Kimi Design 源文件与设计令牌 |
| `docs/` | Kimi Project 时期的项目指令与提示词编译器（网页运行不需要） |

## 开发约定

- 交付形态保持**单文件**：CSS/JS 内联在 `index.html`，不拆分为外部文件。
- 修改 `宫斗模拟器原料/` 中的世界书、文风或提示词后，同步 `index.html` 里对应的常量。
- 样式与脚本的分区见 `index.html` 顶部的目录注释。
