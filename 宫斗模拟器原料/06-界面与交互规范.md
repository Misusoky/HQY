# 界面与交互规范 · 宣纸风 iPhone 版

## 1. 设计令牌

```css
:root {
  /* 色彩：宣纸底 + 朱砂 + 黛蓝 + 墨 */
  --paper:      #f5efe3;  /* 宣纸米白 */
  --paper-deep: #ede4d3;  /* 卡片底/分隔 */
  --ink:        #2b2620;  /* 正文墨 */
  --ink-soft:   #6b6255;  /* 次要文字 */
  --cinnabar:   #a63a2e;  /* 朱砂：选项强调、宠爱、按钮主色 */
  --indigo:     #2f4858;  /* 黛蓝：标题、状态栏、次级按钮 */
  --gold:       #b08d4a;  /* 点缀：位份徽记、分割线 */
  --line:       rgba(43,38,32,.14);
  --shadow:     0 2px 12px rgba(43,38,32,.08);
}
```

- 字体：正文 `system-ui, "Songti SC", "Noto Serif SC", serif`（衬线保证古典感）；数字/状态可用系统无衬线。
- 质感：纸面用极淡的纹理或纯色即可，不要花哨渐变；分隔用细金线或留白。
- emoji 仅用于面板与状态标注（世界书第 12 节允许），正文绝不使用。

## 2. 屏幕结构（单页应用，区块滚动）

```
┌─────────────────────────┐
│ 顶部状态栏（sticky）      │ 元朔五年·正月上旬 ｜ 才人 ｜ 银68两 ｜ 积分90
├─────────────────────────┤
│ 叙事流（主体滚动区）       │ 按旬追加卡片：正文/后宫动态/本旬变化
│                         │
├─────────────────────────┤
│ 选项区（出现时才渲染）      │ 2—4 个全宽按钮 + 「自定义行动」输入框
├─────────────────────────┤
│ 底部操作栏（fixed tab）    │ 状态｜道具｜商城｜存档｜设置
└─────────────────────────┘
```

## 3. iPhone 适配硬要求

- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`
- 全部容器 `padding` 兼容 safe-area（`env(safe-area-inset-*)`）。
- 正文 17px、行高 1.8、段距 1em；标题 20px 起。
- 可点目标 ≥ 44×44pt；选项按钮上下排布全宽，不用横向小按钮。
- 输入框弹出键盘时叙事流不被遮挡（视觉视口处理）。
- 禁止横向滚动、禁止 hover 才能触发的交互、禁止双击缩放。
- 长叙事流懒加载/分页渲染（保留最近 20 旬卡片，更早的折叠为「回顾」）。

## 4. 关键屏幕/组件

### 4.1 开局页
- 标题 + 简介一句；两个入口：【继续旧档（导入 JSON）】【新游戏】。
- 新游戏：调模型按世界书第 14 节生成，展示主角档案卡片（姓名/家世/性格/属性/才艺）供玩家确认，确认后进入第一旬。

### 4.2 旬首安排（FOCUS_SELECT）
- 当前状态栏（时间/位份/体质/银两/积分，一行以内）。
- 生活重心菜单：才艺修习 / 休养康健 / 自由活动与社交 / 宫务与身边经营 / 子女教育 / 家族书信；每项可展开填写具体做法（如「练琴《平沙》」「拜访韦昭仪」）；底部「自定义重心」输入框。

### 4.3 叙事卡片
- 一张旬卡包含：本旬安排（小字）→ 正文 → 后宫动态（传闻前加「传闻」小标）→ 本旬变化（列表，绿升红降）→ 待续事项（小字）。
- 有事件时，旬卡下方渲染选项区并自动滚动到底。

### 4.4 查询面板（底部栏弹出，不耗回合、不调模型）
- 状态（属性/体质/银两/积分）、才艺、关系、道具清单、商城（含积分与购买按钮，购买写入待生效队列，下轮请求时附带）、待续事项、剧情大事记（静态页，直接内置 05 文件内容）。

### 4.5 存档页
- 槽位列表：3 手动 + 1 自动；显示时间/旬次/一句话摘要（statePatch.log）。
- 操作：读取 / 覆盖保存 / 删除 / 导出 .json / 导入 .json（文件选择器）。

### 4.6 设置页
- API Key 输入（密码框，localStorage 存储，附安全提示）、模型选择（kimi-k2 等）、清空本地数据。

## 5. 交互细节

- 生成中：叙事区骨架屏（三行淡入横条），可取消。
- 选项点击后立即禁用全部选项并显示玩家选择（「你选择了：……」），再发请求。
- 自定义行动：输入框 + 发送，与选项互斥。
- 每个选项按钮下方允许一行小字提示代价方向（仅当模型在 option 里给出 hint 字段；否则不显示）。
- 正文过滤：去掉 emoji、markdown 符号残留、代码块包裹。
- 深色模式可选：墨底宣纸反色（#1c1915 底 + 米白字），跟随系统。

## 6. 验收参照

在 iPhone Safari 打开导入 v36 档后：顶部栏显示「元朔四年·十二月下旬｜才人｜银68两｜积分90」；下一旬进入正月上旬；选「才艺修习·练琴」可完整走通 第一轮→选项→第二轮→结算 流程。
